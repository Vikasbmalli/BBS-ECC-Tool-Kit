    ECC + ECDH + AES-GCM

    Two parties agree on a key over an open channel, then use it to encrypt. The artwork shows point addition on a real curve: P + Q = R.

    Learn the theory

    Short answers you can say out loud in a viva.

    How does Blum Blum Shub work?

    Pick two primes p and q that are each 3 mod 4, and let n = p·q. Start from x₀ = seed² mod n. Each round squares the previous state modulo n, and the lowest bit of the new state is the output bit. Predicting the next bit is as hard as factoring n.

    Why must p and q be 3 mod 4?

    It makes every quadratic residue have a square root that is itself a quadratic residue, so the squaring map cycles through states without collapsing. That gives the generator long, well-behaved cycles.

    Is BBS used in real systems today?

    Rarely. It does a modular squaring per bit, so it is slow. Modern systems use faster generators such as ChaCha20 or AES-CTR based designs. BBS is taught because its security argument is clean.

    What is an elliptic curve in cryptography?

    The set of points satisfying y² = x³ + ax + b over a finite field, plus a point at infinity. Points can be added, and repeated addition gives scalar multiplication k·G. Going backwards from k·G to k is the elliptic curve discrete logarithm problem.

    What does ECDH do, and does it encrypt anything?

    ECDH is key agreement. Alice sends dA·G, Bob sends dB·G, and both compute dA·dB·G without ever sending it. It does not encrypt a message by itself, so the demo derives an AES key from the shared secret.

    Why use AES-GCM after ECDH?

    AES-GCM encrypts and authenticates in one step. If anyone changes the ciphertext, the authentication tag check fails and decryption returns nothing. The Tamper button on the ECC page shows this.

    Why is ECC preferred over RSA?

    A 256-bit elliptic curve key gives roughly the same security as a 3072-bit RSA key, so keys are smaller and operations are faster.
